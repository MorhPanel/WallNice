# WallNice branding — concept 1

The production brand mark is concept 1, **Prism W**, on a black background.

## Platform files

- Android adaptive icon: `android/app/src/main/res/drawable/ic_launcher_wallnice.xml` with foreground, background and monochrome system layers.
- Windows: `platforms/windows/wallnice-logo.svg`, black PNG exports and `wallnice-logo.ico`.
- Linux: `platforms/linux/wallnice-logo.svg` and black PNG exports at 256, 512 and 1024 px.
- Shared dark wordmark: `wallnice_wordmark_c1_dark.svg`.

Only dark brand exports are kept. The Android monochrome layer remains solely for the system themed-icon API. The SVG mark uses a 512×512 viewBox and keeps the glyph centered inside the adaptive-icon safe area.
